# 검증 보고서

이 문서는 `pipeline/`으로 일반화한 캠페인 효과 분석의 견고성을 검증한 결과를 정리한다.
개별 캠페인의 상세 결과는 `outputs/campaign_{id}/`(analysis_data.csv, matched_data.csv,
results.json, report.html)를 참고한다.

## 1. 자동화 테스트 (pytest)

`tests/` 34개 테스트, 전부 통과.

| 파일 | 대상 | 방식 |
|---|---|---|
| `tests/test_profitability.py` | 쿠폰 후보안 수익성 계산 | 합성 데이터, 수작업 계산값과 대조 |
| `tests/test_estimate_effect.py` | SMD, 최근접이웃 매칭, 공통지지영역 | 합성 데이터 (대조 재사용 금지·caliper 준수·결정론성 확인) |
| `tests/test_sensitivity.py` | Rosenbaum bounds | Gamma=1일 때 표준 Wilcoxon 검정과 수치 일치 확인 |
| `tests/test_pipeline_integration.py` | 전체 파이프라인 | 캠페인 18(pre_days=586) 결과가 analysis/campaign18_*.py 검증값과 정확히 일치하는지 회귀 확인 |
| `tests/test_generate_report.py` | report.html 생성 | 실제 산출물에 필수 절이 포함되는지 확인 |

실행: `python -m pytest`(느린 통합 테스트 포함) / `python -m pytest -m "not integration"`(빠른 단위 테스트만).

## 2. 30개 캠페인 일괄 실행 (`analysis/campaign_sweep.py`, pre_days=90)

결과: `outputs/campaign_sweep_pre_days_90.csv`

| 상태 | 캠페인 수 |
|---|---:|
| `insufficient_sample` (표본 부족) | 17 |
| `residual_imbalance` (잔여 불균형) | 10 |
| `ok` (품질 기준 통과) | 3 (캠페인 8, 18, 30 — 모두 TypeA) |

**핵심 발견**: 품질 기준을 통과한 3개 캠페인 전부에서, 매칭 후 대상 상품 매출 증분의 95% CI가
0을 포함했다(통계적으로 유의한 캠페인 0개). 캠페인 8은 보정 전 +35.6이던 차이가 매칭 후
-6.2로 부호까지 바뀌었다. 즉 이 데이터셋에서 분석 가능한 캠페인 전반에 걸쳐, 단순 비교에서
보이던 "효과"는 대부분 타겟팅(선택편향)으로 설명되며, 매칭 후 뚜렷한 인과효과가 남는
캠페인은 확인되지 않았다.

## 3. pre_days 민감도 분석 (`analysis/campaign18_pre_days_sensitivity.py`)

캠페인 18을 발행 전 관찰 기간 30/60/90/180/365/586일로 각각 재실행했다.
결과: `outputs/campaign18_pre_days_sensitivity.csv`

| pre_days | status | 매칭후 차이(target_sales) | 95% CI | 유의 |
|---:|---|---:|---|---|
| 30 | ok | 20.08 | [1.82, 38.35] | **예** |
| 60 | residual_imbalance | - | - | 판정 보류 |
| 90 (기본값) | ok | 13.67 | [-4.51, 31.86] | 아니오 |
| 180 | ok | -3.26 | [-21.33, 14.80] | 아니오 |
| 365 | ok | -2.61 | [-21.77, 16.54] | 아니오 |
| 586(전체 이력) | ok | 0.01 | [-19.67, 19.69] | 아니오 |

**핵심 발견**: 결론이 `pre_days` 선택에 민감하다. 발행 전 관찰 기간을 30일로 짧게 잡으면
유의한 양의 효과가 나오지만, 60일 이상에서는 유의성이 사라지고 180~365일에서는 점추정치의
부호까지 음수로 바뀐다. 이는 이 프로젝트가 기본값으로 채택한 `pre_days=90`(및 그 이상)의
"유의한 효과 없음" 결론이 짧은 관찰 기간의 결과와는 다르다는 뜻이며, 아래 4번 민감도 분석과
함께 봐야 한다.

## 4. Rosenbaum 민감도 분석 (`analysis/campaign18_rosenbaum.py`)

관찰되지 않은 교란요인이 얼마나 커야(Gamma) 결론이 뒤집히는지 계산했다.

| pre_days | 결과변수 | 매칭후 차이 | 붕괴점 Gamma (p>0.05) |
|---:|---|---:|---|
| 30 | target_purchase | 0.000 | 1.0 (애초에 비유의) |
| 30 | **target_sales** | 20.08 | **1.2** |
| 30 | **target_quantity** | 7.04 | **1.2** |
| 90 | target_purchase | 0.000 | 1.0 (애초에 비유의) |
| 90 | target_sales | 13.67 | 1.0 (애초에 비유의) |
| 90 | target_quantity | 5.34 | 1.0 (애초에 비유의) |

**핵심 발견**: pre_days=30에서 얻은 "유의한" target_sales·target_quantity 효과는 Gamma=1.2,
즉 처치 배정 승산을 단 20%만 왜곡하는 수준의 아주 작은 숨겨진 교란만으로도 유의성이
사라지는 매우 취약한(fragile) 결과다. 통상 Gamma 2~3 이상을 견뎌야 "어느 정도 강건하다"고
보는 경험칙에 크게 못 미친다. 3번 항목의 pre_days 민감도와 종합하면, **캠페인 18의 "긍정적
효과"로 보였던 결과는 관찰 기간을 짧게 잡았을 때만, 그것도 아주 약한 숨겨진 편향에도
쉽게 뒤집히는 수준으로만 나타난다** — 신뢰하기 어려운 신호로 판단한다.

## 5. 종합 결론

1. 보정 전 단순 비교는 캠페인 18을 포함한 여러 캠페인에서 뚜렷한 "효과"를 보였지만, 이는
   대부분 발행 전 구매행동 차이(선택편향)로 설명된다. 품질 기준을 통과한 3개 캠페인 모두
   매칭 전 최대 SMD가 0.67~1.41로 컸으나 매칭 후 0.04~0.09로 크게 줄었다(캠페인 8:
   0.670→0.041, 캠페인 18: 0.688→0.047, 캠페인 30: 1.406→0.091 — 재실행 2회로 결정론적
   재현 확인), 동시에 효과 추정치도 대부분 0에 가깝게 축소되었다.
2. 품질 기준을 통과한 3개 캠페인(8, 18, 30) 중 매칭 후 통계적으로 유의한 순수 효과를 보인
   캠페인은 없다.
3. 유일하게 유의했던 사례(캠페인 18, pre_days=30)는 관찰 기간 선택에 민감하고 숨겨진 교란에도
   극도로 취약해, 신뢰할 만한 인과효과의 근거로 보기 어렵다.
4. 이 결론은 "캠페인이 전혀 효과가 없다"는 확정이 아니라, "이 데이터와 방법으로는 신뢰할 만한
   양의 효과를 찾지 못했다"는 의미로 해석해야 한다(매칭 표본이 원 처치 가구의 약 40~65%로
   제한적이고, 관찰되지 않은 교란도 완전히 배제할 수 없음).

## 6. 남은 한계

- `report.html`은 캠페인 8/18/30(품질 기준 통과 3건)에 대해서만 생성했다. 나머지 27개
  캠페인은 `results.json`에 상태와 사유만 기록되어 있다.
- 인구통계 변수는 커버리지 문제로 결측 지시자(`has_demographic`)만 사용했다 —
  값 자체를 활용한 별도 민감도 분석은 수행하지 않았다.
- pre_days 민감도는 캠페인 18 하나에 대해서만 확인했다. 다른 캠페인도 동일한 패턴을
  보이는지는 별도 확인이 필요하다.
